# API YaMDb

REST API для проекта **YaMDb** — сервиса отзывов о произведениях.

Пользователи могут оставлять отзывы и комментарии к произведениям, выставлять оценки, а также управлять контентом через систему ролей.

Проект разработан на основе **Django REST Framework**.

---

## Возможности проекта

### Пользователи и роли

В проекте реализована система ролей:

### Анонимный пользователь

Доступно:

- просмотр произведений;
- просмотр отзывов;
- просмотр комментариев.

---

### Обычный пользователь (`user`)

Доступно:

- регистрация;
- получение JWT-токена;
- просмотр и изменение собственного профиля;
- создание отзывов;
- редактирование своих отзывов;
- удаление своих отзывов;
- создание комментариев;
- редактирование своих комментариев;
- удаление своих комментариев.

---

### Модератор (`moderator`)

Имеет все возможности обычного пользователя.

Дополнительно:

- редактирование любых отзывов;
- удаление любых отзывов;
- редактирование любых комментариев;
- удаление любых комментариев.

---

### Администратор (`admin`)

Полный доступ к API:

- управление пользователями;
- управление произведениями;
- управление категориями;
- управление жанрами;
- управление всем контентом.

---

# Основной функционал

## Произведения

API позволяет:

- получать список произведений;
- искать произведения;
- фильтровать произведения;
- просматривать подробную информацию.

Каждое произведение содержит:

- название;
- год выпуска;
- описание;
- категорию;
- жанры;
- рейтинг на основе пользовательских отзывов.

---

## Категории

Администратор может:

- создавать категории;
- удалять категории.

Примеры:

```

Фильм
Книга
Музыка

```

---

## Жанры

Администратор может:

- создавать жанры;
- удалять жанры.

Примеры:

```

Комедия
Драма
Фантастика

````

---

## Отзывы

Пользователи могут:

- создавать отзывы;
- просматривать отзывы;
- редактировать свои отзывы;
- удалять свои отзывы.

Ограничения:

- один пользователь может оставить только один отзыв на одно произведение;
- оценка выставляется от **1 до 10**.

---

## Комментарии

Пользователи могут:

- создавать комментарии к отзывам;
- просматривать комментарии;
- изменять свои комментарии;
- удалять свои комментарии.

# Импорт тестовых данных из CSV
В проекте предусмотрен скрипт для импорта тестовых данных из CSV-файлов. Данные должны находиться в директории static/data/.

## Важно: Импорт необходимо выполнять в указанном порядке для соблюдения зависимостей между моделями.

Команда для импорта:
```
bash
python manage.py import_csv
```
## Порядок импорта данных:
Скрипт автоматически импортирует данные в следующем порядке:
```
Категории (category.csv) - категории произведений
Жанры (genre.csv) - жанры произведений
Произведения (titles.csv) - основные произведения
Связи произведений и жанров (genre_title.csv) - многие-ко-многим
Пользователи (users.csv) - пользователи системы
Отзывы (review.csv) - отзывы на произведения
Комментарии (comments.csv) - комментарии к отзывам
```

# Аутентификация

Проект использует JWT-аутентификацию.

## Регистрация пользователя

Метод:

```
POST /api/v1/auth/signup/
```

Пример запроса:

```json
{
    "email": "user@mail.com",
    "username": "username"
}
```

Ответ:

```json
{
    "email": "user@mail.com",
    "username": "username"
}
```

После регистрации пользователь получает код подтверждения на email.

---

## Получение JWT-токена

Метод:

```
POST /api/v1/auth/token/
```

Запрос:

```json
{
    "username": "username",
    "confirmation_code": "123456"
}
```

Ответ:

```json
{
    "token": "jwt_token"
}
```

Использование токена:

```http
Authorization: Bearer <token>
```

# API Endpoints

## Пользователи

| Метод  | Endpoint                    | Описание                       |
| ------ | --------------------------- | ------------------------------ |
| GET    | `/api/v1/users/`            | Получить список пользователей  |
| POST   | `/api/v1/users/`            | Создать пользователя           |
| GET    | `/api/v1/users/{username}/` | Получить пользователя          |
| PATCH  | `/api/v1/users/{username}/` | Изменить пользователя          |
| DELETE | `/api/v1/users/{username}/` | Удалить пользователя           |
| GET    | `/api/v1/users/me/`         | Получить текущего пользователя |

---

## Категории

| Метод  | Endpoint                     | Описание           |
| ------ | ---------------------------- | ------------------ |
| GET    | `/api/v1/categories/`        | Получить категории |
| POST   | `/api/v1/categories/`        | Создать категорию  |
| DELETE | `/api/v1/categories/{slug}/` | Удалить категорию  |

---

## Жанры

| Метод  | Endpoint                 | Описание       |
| ------ | ------------------------ | -------------- |
| GET    | `/api/v1/genres/`        | Получить жанры |
| POST   | `/api/v1/genres/`        | Создать жанр   |
| DELETE | `/api/v1/genres/{slug}/` | Удалить жанр   |

---

## Произведения

| Метод  | Endpoint               | Описание                     |
| ------ | ---------------------- | ---------------------------- |

| PATCH  | `/api/v1/titles/{id}/` | Изменить произведение        |
